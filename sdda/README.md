# SDDA

This project is an amalgam of the ideas in `Sumo-Tools/makefile` and `src/introspection`.

If successful, both of those packages will be deleted.

## Purpose

SDDA stands for Static Data-Dependency Analyser.

The project exists to determine what non-code file families may be needed, produced, or observed by Sumo-Tools code, so that distribution and reproduction decisions can be made explicitly.

The initial requirements and specification are in:

```text
sdda/docs/SDDA Requirements.md
sdda/docs/SDDA Specification.md
```
