# Definition: Elo rating calculation

## 1. Objects

Let:

* (R = \mathbb{R}) — rating space
* (O = {0,1}) — outcome space (win = 1, loss = 0)
* (Q \in \mathbb{R}_{>0}) — fixed scale parameter
* (B \in \mathbb{R}) — fixed initial rating
* (\mathrm{Rank}) — set of ranks
* (K : \mathrm{Rank} \to \mathbb{R}_{>0}) — K-factor function

Let a **bout** be a tuple:
[
(i, j, o)
]
where:

* (i, j) are rikishi
* (o \in O) is the outcome for (i)

Let a **history** be an ordered sequence of bouts:
[
H = (b_1, b_2, \dots, b_T)
]

Each rikishi has a rank at each bout:
[
\rho(i, t) \in \mathrm{Rank}
]

---

## 2. Expected score

For ratings (e, e' \in R), define:

[
E(e, e') = \frac{1}{1 + 10^{(e' - e)/Q}}
]

---

## 3. Rating state

A **rating state** at time (t) is a function:

[
r_t : \mathrm{Rikishi} \to R
]

with initial condition:

[
r_0(i) = B \quad \forall i
]

---

## 4. Update rule (single bout)

Given bout (b_t = (i, j, o)), define:

[
\Delta = K(\rho(i,t)) \cdot \bigl(o - E(r_{t-1}(i), r_{t-1}(j))\bigr)
]

Then:

[
r_t(i) = r_{t-1}(i) + \Delta
]
[
r_t(j) = r_{t-1}(j) - \Delta
]

and for all other rikishi (k):

[
r_t(k) = r_{t-1}(k)
]

---

## 5. Elo rating calculation

Given a history (H), the **Elo rating calculation** is the sequence:

[
(r_0, r_1, \dots, r_T)
]

obtained by iteratively applying the update rule for each bout in order.

The **final ratings** are (r_T).

---

# Summary (one sentence)

> Elo rating calculation is the iterative application of a pairwise update rule over an ordered sequence of contests, where expected outcomes are determined by a logistic function of rating differences, and rating changes are scaled by a rank-dependent K-factor.

---

## Advisory notes (contract-level clarity)

* This definition assumes:

  * a total ordering of bouts (time is linearized)
  * ratings exist for all rikishi at all times (initialized to (B))
* The only domain-specific extension is:
  [
  K = K(\rho)
  ]

Everything else is canonical Elo.
