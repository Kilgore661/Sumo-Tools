How large can the small-\(K\) bound be?

This upper bound on \(K\), which we shall call \(K_{\max}\), may seem surprisingly small. A natural question is whether some choices of \(q\) make \(K_{\max}\) substantially larger—perhaps of the order of 10 rating points.

Write \(R\) for the largest difference between any two true ratings: in other words, the full width of the rating range. With the usual 0-to-1 Elo scoring convention, the sufficient upper bound derived from Cortez and Tossounian’s condition can then be written \[ K_{\max}(q,R) =\frac{\ln 10}{2q} \operatorname{sech}^{2}\!\left( \frac{(1+R)\ln 10}{2q} \right). \] Here the midpoint of the rating range has been used as zero. This centring does not alter any Elo probabilities, which depend only on rating differences.

Thus the bound is not sensitive to the absolute level of the ratings: adding 1,000 points to every rating changes nothing. It is sensitive to the numerical width of the rating range relative to \(q\). To make this concrete, suppose that ratings are intended to run from 1,000 to 1,400.
