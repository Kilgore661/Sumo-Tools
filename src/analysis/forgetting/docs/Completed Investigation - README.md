# Fixed-Skill Forgetting Study: Document Guide

The completed study is recorded in three layers:

1. [Completed Investigation: Forgetting in a Fixed-Skill Toy
   World](Completed%20Investigation%20-%20Forgetting%20in%20a%20Fixed-Skill%20Toy%20World.md) — the readable end-to-end account, results, interpretation, conclusion, and limits.
2. [Completed Investigation: Technical
   Companion](Completed%20Investigation%20-%20Technical%20Companion.md) — code map, commands, exact run directories, artifacts, schemas, extraction rules, and reconstruction checks.
3. [Proposal 1: Forgetting in a Fixed-Skill Toy
   World](Proposal%201%20-%20Forgetting%20in%20a%20Fixed-Skill%20Toy%20World.md) — the design record, vocabulary, completed status, and formal claim boundary.

For a future reader, start with the completed investigation. Consult the
technical companion when checking a number, locating an artifact, rerunning
code, or interpreting a historical filename. Return to the proposal when the
question concerns why the experiment was designed as it was or what it was
never intended to establish.
