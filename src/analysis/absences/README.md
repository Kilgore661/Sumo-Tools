# Absences

This analysis area explores the question of whether the historical record can
tell us when a sub-sekitori rikishi was kyujo.

The work begins with an isolated empirical check of the Japan Sumo
Association's normal seven-window schedule for makushita, sandanme, jonidan
and jonokuchi rikishi.  No use of the findings outside this analysis area is
assumed.  Possible applications will not be considered until the experiment
has concluded.

## Experiments

- `jsa_check`: compare recorded sub-sekitori schedules with the JSA's stated
  pattern of one bout-related outcome in each of seven scheduling windows.
