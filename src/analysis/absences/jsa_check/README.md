# JSA Check

JSA Check is an isolated empirical experiment within the `absences` analysis
area.

Its question is:

> How consistently do recorded sub-sekitori schedules follow the Japan Sumo
> Association's normal seven-window guideline?

The experiment covers makushita, sandanme, jonidan and jonokuchi from January
1989 onward.  It first reconciles dated bout-related outcomes with the final
win, loss and absence totals, then measures departures from the expected
one-outcome-per-window pattern.

The experiment does not infer particular kyujo days, explain why a departure
occurred, or propose changes elsewhere in the project.
