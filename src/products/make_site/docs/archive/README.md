# Archived make_site Docs

This directory preserves older design notes, inventories, and stress-test
documents.

Archived does not mean useless. These notes record the reasoning path that led
to the current public-site structure. They should not be treated as the first
source of current policy, but they remain useful when reconstructing why a page,
contract, or navigation idea exists.
