# 02.9 Specification - Longest Careers

## Status

Settled first-pass specification for Sumo History > Records > Longest careers.

---

## 1. Public Question

The page answers:

```text
Which rikishi have the longest observed careers?
```

This is a career-length record. It ranks rikishi by elapsed time between first
and last banzuke appearances in the prepared History. It does not rank by bout
count, active service days, top-division tenure, or continuous appearance.

---

## 2. Public Artifact

The PA is an ordinary Records table headed:

```text
Longest Careers
```

The table columns are:

| Column | Meaning | Sortable |
| --- | --- | --- |
| blank | row number after current filtering and sorting | no |
| `#` | record position for the selected active/retired population | yes |
| `Shikona` | rikishi shikona, linking to SumoDB | yes |
| `First` | first observed banzuke appearance | yes |
| `Last` | last observed banzuke appearance | yes |
| `Years` | observed elapsed career length in years | yes |
| `Bg` | number of basho for which the rikishi was absent | yes |

`Years` has the popover note:

```text
Years is the observed career length: the elapsed time between the first and
last banzuke appearances in the prepared history.
```

`Bg` has the popover note:

```text
Bg is the number of basho for which the rikishi was absent.
```

The producer may carry active status as a hidden row-selection field, but active
status is not a visible table column in the Records page.

---

## 3. Filters and Public State

The page has one option:

```text
Show Active?
```

It is a checkbox and is checked by default.

When `Show Active?` is checked, the table shows the ranked all-rikishi
population. When unchecked, the table shows the separately produced
non-active population. Each population has its own top-N ranked view, and `#`
continues to show the producer-owned position in that selected population.

The default published candidate limit is the sitewide `TOP_N_LIMIT`, currently
50 rows.

---

## 4. Data Contract

The staged CSV for the PA is:

```text
sumo-history/records/longest-careers/data/longest.csv
```

This page reuses the Career Length producer's source material, but its public
staged path mirrors the Records page location.

The source material is currently produced by:

```text
src.analysis.sumo_history.career_lifecycle.career_length
```

`make_site2` materializes the two ranked populations consumed by the runtime:

```text
longest_population = all
longest_population = non_active
```

`rikishi_id` is required even though it is not a visible table column, because
the public `Shikona` values link to SumoDB.
