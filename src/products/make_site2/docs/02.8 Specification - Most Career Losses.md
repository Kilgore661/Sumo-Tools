# 02.8 Specification - Most Career Losses

## Status

Settled first-pass specification for Sumo History > Records > Most career
losses.

---

## 1. Public Question

The page answers:

```text
Which rikishi have the greatest number of career losses?
```

This is a career-total record. It does not normalise by career length, number
of bouts, division or era.

---

## 2. Public Artifact

The PA is an ordinary flat table headed:

```text
Most Career Losses
```

The table columns are:

| Column | Meaning | Sortable |
| --- | --- | --- |
| blank | row number after current filtering and sorting | no |
| `#` | record position for the selected option state | yes |
| `Shikona` | rikishi shikona, linking to SumoDB | yes |
| `Losses` | career losses under the selected fusen policy | yes |
| `Wins` | career wins under the selected fusen policy | yes |
| `Bouts` | `Wins + Losses` under the selected fusen policy | yes |
| `Win rate` | `Wins / Bouts`, displayed as a percentage | yes |
| `Start` | first counted win/loss decision | yes |
| `End` | final counted win/loss decision, or `-` for active rikishi | yes |

`Start` and `End` values use `YYYY/MM/DD`, where `DD` is the basho day number,
not a civil calendar day. Their popover text is:

```text
year/month/day of basho
```

---

## 3. Filters and Public State

The page has two options:

```text
Include retired?
Count fusen results?
```

Both are checkboxes and both are checked by default.

When `Include retired?` is unchecked, the table shows only rikishi active in the
current History. History is current for this page, so active means listed on
the latest represented banzuke.

When `Count fusen results?` is checked, fusensho count as wins and fusenpai
count as losses. When unchecked, fusensho and fusenpai are excluded from wins,
losses, bouts, win rate and start/end decision dates.

Each option state has its own top-N ranked view. The default published candidate
limit is the sitewide `TOP_N_LIMIT`, currently 50 rows.

---

## 4. Data Contract

The staged CSV for the PA is:

```text
sumo-history/records/most-career-losses/data/career_losses.csv
```

The source CSV is currently produced at:

```text
files/output/analysis/sumo_history/records/career_losses/career_losses.csv
```

The producer may emit the union of rows needed by the four top-N option states:

```text
include retired + count fusen
include retired + exclude fusen
active only + count fusen
active only + exclude fusen
```

`rikishi_id` is required even though it is not a visible table column, because
the public `Shikona` values link to SumoDB.
