# Matters Arising from the Elo-89 Expert Account

This directory records research questions exposed by the current expert
account which are not part of the retained Elo-89 model. A matter belongs here
when it requires its own investigation and could change a future model, but
has not yet produced an accepted replacement for the current contract.

## Open matters

### [Entrant Prior Mapping Optimisation](Entrant%20Prior%20Mapping%20Optimisation/README.md)

Explore whether modern optimisation or statistical estimation methods can
find a better chii-to-first-rating mapping than the early-stopped iterative
path used to construct P89. Any candidate must be evaluated with explicit
regularisation and evidence outside the data used to fit it.

## Status convention

Each matter should state whether it is a proposal, implemented experiment,
completed investigation or accepted decision. Merely appearing in this
directory does not change P89, Elo-89 production, or the public website.
