# Elo-89 Expert Account

This directory is the current **top copy** of the expert account of the
Elo-89 model. It is undergoing its final substantive and publication review.

The account is written for readers familiar with rating theory. It explains
the current model, the reasons for its principal choices, the evidence
supporting them and the limits of the resulting claims. Implementation detail
is included in the chapters only where it affects the model's meaning or is
needed for exact specification.

The chapter sequence and reading map are in [00 Contents](00%20Contents.md).
Detailed research, implementation and artifact references are collected in
the [Research and Implementation Guide](Appendix%20-%20Research%20and%20Implementation%20Guide.md).
The construction of the frozen entrant prior is described separately in the
preliminary [Appendix B](Appendix%20B%20-%20The%20Elo-89%20Entrant%20Prior.md).

The preceding account remains preserved in
[`../elo89-expert-account`](../elo89-expert-account), together with the
Matters Arising investigations which led to this edition.

The P89 values are persisted at
[`equelo_prior_aggregation/results/priors.csv`](../../analysis/equelo_prior_aggregation/results/priors.csv)
and documented in the [P89 production README](../../analysis/elo89/prior/README.md).
Website integration remains separate from the account itself.
