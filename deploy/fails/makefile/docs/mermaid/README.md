# Mermaid Graph Views

This folder is for Mermaid source templates or notes that support graph rendering.

Do not put generated graph output here.

Charts are produced on demand from the canonical CSV inventories. They are views, not required audit deliverables.

Generated graph files should be written under:

```text
files/output/makefile/mermaid/
files/output/makefile/html/
files/output/makefile/svg/
```

The canonical graph data should be CSV-style inventory files, not Mermaid.

Mermaid is a view of the audit data.
